# Keterbatasan, batas klaim, ancaman validitas

Batas utama adalah **ketersediaan fitur**: curah hujan tahunan, suhu dan penggunaan pestisida bisa baru final setelah akhir tahun/panen. Menyebutnya forecast sebelum musim tanam berpotensi memakai informasi masa depan pada saat pengambilan keputusan, meskipun evaluasi kronologis tidak mencampur tahun.

Statistik wilayah tidak langsung berlaku pada lahan individual. Pasangan area/tanaman berulang antarsplit; belum ada bukti OOD geografis. Kategori baru diabaikan encoder dan dapat menghasilkan angka yang tampak masuk akal tetapi tidak reliabel. Perubahan iklim, data masa depan, metode pengukuran dan error antar-tanaman membutuhkan validasi prospektif. Lisensi serta ekuivalensi data hulu belum terverifikasi; belum ada bukti deployment publik, pilot lahan, coverage interval, atau audit keamanan keputusan otomatis.
